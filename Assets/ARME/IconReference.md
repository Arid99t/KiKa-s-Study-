## Usage Tips

### Best Practices:
1. **Stick to simple icons** for better compatibility across platforms
2. **Use consistently** - establish icon meanings in your project
3. **Test on your target platforms** before committing to specific icons
4. **Consider fallback text** for critical information

### Code Examples:
```csharp
// Good for all platforms
Debug.Log("✅ Connection established");
Debug.LogError("❌ Failed to connect");
Debug.LogWarning("⚠️ Low battery");

// Audio-specific examples
Debug.Log("▶️ Playback started");
Debug.Log("🎵 Loading audio clip: " + clipName);
Debug.Log("🔊 Volume set to: " + volume + "%");
Debug.Log("🎛️ Mixer initialized with " + channelCount + " channels");

// Debugging examples
Debug.Log("🔍 Searching for player controller...");
Debug.Log("🚀 Initializing ARME systems...");
Debug.Log("🔧 Applying audio effects...");
Debug.Log("📊 Performance: " + fps + " FPS");
```

### PowerShell Compatibility Note:
PowerShell may not display all Unicode emojis properly depending on:
- Windows version
- Console font settings
- Terminal application used (Windows Terminal vs legacy console)

For maximum PowerShell compatibility, prefer simple symbols like: ✅ ❌ ⚠️ ▶️ ⏸️ ⏹️
